# CodexAutoRelay

CodexAutoRelay is a closed-source macOS desktop utility for relay workflows between Codex and a web-based reviewer.

## Download

Download the latest notarized build from the Releases page. The recommended asset is CodexAutoRelay-1.0-1.zip.

## What it does

The app captures screenshots from a selected screen region, reads completion markers with OCR, and relays prompts and replies between a reviewer app and a target app. It also includes coordinate calibration and optional local session archives for troubleshooting.

## Requirements

CodexAutoRelay requires macOS, Screen Recording permission, Accessibility permission, and both the reviewer app and target app running before a session starts.

## Permissions

Screen Recording is used to capture the configured region for OCR and relay steps. Accessibility is used to focus apps, click configured points, paste text, and send keyboard shortcuts in your relay workflow.

## Install

Download the latest notarized ZIP, extract CodexAutoRelay.app, move it to Applications, open it, and grant the requested permissions. Then configure the screen region, input points, copy points, and bundle IDs before starting a session.
