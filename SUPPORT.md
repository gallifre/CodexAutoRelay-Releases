# Support

This repository is the public support home for the notarized release build of CodexAutoRelay.

## What to include

When you report a problem, include the app version, your macOS version, whether Screen Recording and Accessibility are enabled, the reviewer app and target app you are using, and the exact step where the relay stopped or behaved incorrectly.

## Helpful attachments

Redacted screenshots, short log excerpts, and a redacted session archive summary can help reproduce a problem faster.

## Safety

Do not post private prompts, screenshots, API keys, access tokens, or personal information in public issue reports.

## Best channel

Use GitHub Issues in this repository for bug reports, installation problems, Gatekeeper or notarization launch issues, and feature requests.

## Common checks

Make sure you downloaded the official ZIP from the Releases page, extracted the app before opening it, moved the app to Applications, granted both required permissions, and rechecked your coordinates, bundle IDs, and wait timings.

## Response scope

Support for the public release build is best effort.
