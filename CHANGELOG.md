# Changelog

This file records notable public release changes for the closed-source distribution of CodexAutoRelay.

## 1.0.0 - 2026-06-12

This is the first public standalone macOS release of CodexAutoRelay.

The release is Developer ID signed, Apple notarized, and distributed outside the Mac App Store.

The app includes setup for screen regions, input points, copy points, wait timing, and bundle IDs.

The app also includes OCR marker detection, prompt rendering, calibration tools, local logs, and optional session archives.
